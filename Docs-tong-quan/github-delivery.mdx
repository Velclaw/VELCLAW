# GitHub & delivery

Velclaw connects repository integration, code review, validation, and delivery into one engineering workflow.

## GitHub integration

The source tree contains GitHub API routes, authentication/integration code, repository and pull-request UI components.

## Prepare review

Keep proposed changes focused, inspect the diff, and provide enough context for reviewers to evaluate the change.

## Deliver deliberately

Use build, lint, type-check, CI, and review signals before deciding that a change is ready to ship. Real GitHub delivery operations require appropriate credentials and repository permissions.

## Keep traceability

Link implementation, validation, review, and release information so the delivery decision can be understood later.
