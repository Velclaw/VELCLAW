## Velclaw ecosystem

Velclaw is organized around a connected software lifecycle:

```text
AI Agents
    │
    ▼
Workspace → Code → Build → Runtime
    │                     │
    ▼                     ▼
GitHub & Review ─────→ Deployment
```

The canonical Velclaw product host is `velclaw.cfd`. The documentation site is **docs.velclaw.ai**.

## Core areas

- **Workspace** — projects, files, context, and state.
- **Agents** — agent roles, tools, sandbox execution, and review.
- **Build & runtime** — Next.js application stack, validation, CI, and runtime.
- **GitHub & delivery** — repository integration, review, CI, and release traceability.
- **Security** — access boundaries, secrets, and sensitive-change review.
