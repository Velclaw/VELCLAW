# Workspace

A Velclaw workspace groups the files, instructions, and state needed for a software task so developers and agents can work from the same source of truth.

## Organize projects

A project is the working boundary for a software task. Keep its source files, configuration, instructions, and relevant state together.

## Preserve context

Keep project context close to the code rather than relying on isolated prompts.

- Project files and configuration
- Task-focused context
- Visible working state
