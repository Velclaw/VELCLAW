# GitHub & phân phối

Velclaw kết nối tích hợp kho mã, review mã, kiểm tra hợp lệ và phân phối vào một quy trình kỹ thuật thống nhất.

## Tích hợp GitHub

Cây mã nguồn chứa các route API GitHub, mã xác thực/tích hợp, các thành phần UI cho kho mã và pull request.

## Chuẩn bị review

Giữ các thay đổi đề xuất tập trung, kiểm tra diff và cung cấp đủ ngữ cảnh để người review đánh giá thay đổi.

## Phân phối có chủ đích

Dùng các tín hiệu build, lint, kiểm tra kiểu, CI và review trước khi quyết định một thay đổi đã sẵn sàng phát hành. Các thao tác phân phối GitHub thực tế yêu cầu thông tin xác thực và quyền kho mã phù hợp.

## Duy trì khả năng truy vết

Liên kết thông tin triển khai, kiểm tra hợp lệ, review và phát hành để quyết định phân phối có thể được hiểu về sau.
