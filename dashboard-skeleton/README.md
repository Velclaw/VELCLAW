# Velclaw Dashboard Skeleton

Khung xương Dashboard theo design system Velclaw (nền tối, violet, monospace, góc vuông) và bố cục giống Cursor.

## Routes
- `/`
- `/docs`
- `/auth`
- `/dashboard`
- `/chatbot`
- `/work/agent/chat/codehub`
- `/VelclawHub`
- `/mcp.velclaw.com`
- `/api.velclaw.com`

## Chạy
```bash
cd dashboard-skeleton
npm install
npm run dev
```

Tuân thủ DESIGN_SYSTEM.md của repo.
