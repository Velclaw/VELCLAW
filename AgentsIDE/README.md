# AgentsIDE

AgentsIDE is an AI-native coding workspace for building, reviewing, testing and shipping software.

## Product loop

**Workspace → Agent → Edit → Test → Review → Git → Deploy**

## Foundation

- React + TypeScript + Vite
- Mobile-first responsive shell
- Workspace, Code, Agent, Review and Tools navigation
- Dark developer-focused UI
- Ready for real editor, terminal, GitHub and agent execution integrations

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Roadmap

1. Real file system + Monaco editor
2. Agent task/execution runtime
3. Diff engine and review gates
4. Terminal and test runner
5. GitHub branch/commit/PR integration
6. Deployment adapters
7. Authentication, workspace persistence and settings
